# Audi Lexington Q7 and Q9 evening

A one-page invitation for Audi Lexington’s evening introducing the new Q7 and the all-new Q9.

Friday, October 30, 2026, 6:00 to 8:00 PM
3000 Pink Pigeon Pkwy, Lexington, KY 40509

## GitHub Pages

Publish the repository root. There is no build step. `index.html` is the site.

## RSVP

`rsvp-config.js` sets `window.RSVP_ENDPOINT`. It ships as an empty string. The form posts JSON to that URL once a value is set. While the endpoint is empty, a completed form does not report that a request was saved.
